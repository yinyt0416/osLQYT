# CVE-2017-6346：10 轮配对重复实验

本目录保存 RQ3 正式采用的 10 轮 Native/PERIOD 配对实验逐轮数据与汇总结果。该实验使用目标进程单次调用延迟作为 slowdown 口径。早期五轮整轮计时结果已移入 `../archive/five_round_legacy/`，仅供追溯，不能与本实验合并。

## 有效性规则

仅当同一轮的 Native 与 PERIOD 状态均为 `OK` 时，才计算配对 slowdown。10 轮中 7 轮有效；第 7、10 轮因目标进程超时排除，第 8 轮因没有完成任何目标进程调用排除。所有轮次均保留在 CSV 中，未静默删除异常值。

## 结果

| 指标 | 数值 |
|---|---:|
| 有效配对 | 7 / 10 |
| Native 单次延迟均值 | 7.858 ms |
| PERIOD 单次延迟均值 | 299.236 ms |
| slowdown 均值 | 53.66× |
| slowdown 中位数 | 58.22× |
| slowdown 范围 | 14.12×–68.30× |
| PERIOD 整轮搜索时间均值 | 54.79 s |
| 每个有效轮完成调用数 | 182 |

第 9 轮 Native 基线明显变慢，使 slowdown 降至 14.12×；因此展示典型开销时应同时报告中位数 58.22×、均值 53.66×和有效轮比例，避免只报单一数字。

文件说明：

- `rq3_repeat10_rounds.csv`：10 轮逐轮状态和计时；
- `rq3_repeat10_summary.json`：按上述规则生成的机器可读汇总。
